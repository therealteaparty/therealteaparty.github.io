Milky Way Cafe

A cosmic barista simulator

Development: Unreal Engine 5, Unreal Blueprints

Art: Autodesk Maya

Timeline: 3 Weeks

Milky Way Cafe is meant to provide a light-hearted game experience to busy the player with mundane tasks in a visually interesting environment. Playing on pastel colors and a cartoon shaded space, the first ever appearance of originally created android characters are introduced. The game's mechanics are based on a randomized ordering system combined with a physics handle used to interact with items.

About the Process

Developed for an intermediate Game Production course at Indiana University, this game was meant to explore the application of general programming skills to rules in game design.

After greyboxing the scene, I developed original 3D assets including the robot characters, furniture, and interactable items. These objects were transformed into actors that could be used in gameplay

The goal of this project was to create a gameplay loop towards a simple goal. Using Unreal BP, I practiced creating loops with enough randomization to create a seemingly endless gameplay loop.

Utilizing and understanding raycasting was the most important takeaway of this game. Raycasts were used in conjunction with Unreal physics handle to pick up and interact with the correct objects.
