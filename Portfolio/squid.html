There's a Squid in My Snack!

A mini-game created for a local game jam

Development: Godot 4, GDScript

Art: Procreate

Timeline: 48 Hours

There's a Squid in my Snack! was created on a team of three for a local game jam, which took place in 48 hours. The theme, 'Inside Out,' was interpreted as the player escapes capture from the inside of a vending machine. An extra incentive for moving around the machine is a collectable candy, in which you can collect all, some, or none of. My contrubution on this project emphasized user interface development, gameplay programming, input handling, random events, timers, and scene management.

About the Process

This game was created for an introductory Game Programming class at the Media School at Indiana University. My team of two was given a theme to develop in a short amount of time. We knew that an arcade type of game would give us the best chance of creating something interesting and fun within a small scope.

The player can navigate thorugh a grid of spaces with the goal of collecting candies, as well as avoiding random 'danger' spaces.

I took the lead on developing the basic classes and methods for the game, as well as connecting the user interface to player inputs.

The most challenging part of development was creating dynamic animations that responded to my algorithm for choosing random spaces on the grid. However, this system ended up receiving the most positive feedback from instructors and peers.
