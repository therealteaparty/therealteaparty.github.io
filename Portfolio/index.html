The Art Market

Preview Website on Zion

HTML, CSS, PHP, JavaScript, MySQL, MariaDB

The IU Art Market is a involved information system backed by an organized, original databse. It hosts and remembers user data and reponds dynamically to forms and input. The site was created to solve a real-world problem within the University through a usable, intuitive, and accessible platform.

Preliminary stages of developing this system involved database design, user story design, mid to high fidelity wireframe development, primary research and surveys, and multiple iterations of a final dynamic website. It took half of a semester to plan the project, and then one full semester to bring the site through full development and iteration

My personal role with The Art Market landed in back-end PHP and MySQL development. I took the lead on organizing, saving, cleaning, and fetching data and inputs. I was able to explore the most optimal ways to design a database, especially in regards to joining relationships between tables and understanding how to order and validate incoming data. An additional success of this project includes integrating PHP functionality with responsive HTML elements, and creating a balance between intuitive functionality and a friendly design.

T-Day

Visit T-Day

HTML, CSS, JavaScript

T-Day is a personal blog in the form of a static website. It was initially created for a final project in Web Design at Indiana University. The site is meant to invite a casual and informal audience to explore trivial information about myself. The underlying purpose of the site was to design an interesting and functioning themed website around written content.

Throughout the process of creating T-Day, I explored intermediate and advanced teqniques for creating dynamic web designs. Most importantly, I practiced progressive enhancement as a means to provide accesibility to multiple screen sizes. Beginning with the smallest narrow, mobile design, I slowly expanded my styles until the website could fit a large monitor screen.

Secondly, I learned a lot about the integration of JavaScript as a means to create smoother interactions within a website. The most useful technique was the ability to add a collaspable navigation menu.

The third most important skill mastered through T-Day has been the use of Flexbox. You may see instances of organizing text, images, galleries, and links with responsive layouts using Flexbox.

This Website

HTML, CSS, JavaScript

This site handles a wide variety of visual content, such as 2D illustrations, copy, logos, 3D objects, video, and embedded external content. With a comphrehensive style and theme, each element has been put together in a cohesive portfolio website.

A huge lesson learned throughout the development of this website was improving optimization of web design resources. The base HTML of this website was first created at a time when I had the least experience, and then slowly iterated upon up until today. There has been much room for improvement when it comes to consolidating my stylesheets, creating and utilizing functions, and organizing HTML elements in a more secured structure.
