Rainbow Cat Space Shooter

A classic 4-directional space shooter

Development: Godot 4, GDScript

Art: Procreate

Timeline: 2 Weeks

Rainbow Space Shooter is the first game Téa has ever created with a graphical interface, sound, and working mechanics with user input. It is a quick and simple classic space shooter with a comedic twist using a personal artistic style. Develoment of this game emphasized learning clean and strong computational foundations for loops, data strcutures, and functions.

About the Process

Being completely new to developing game interfaces and programming for games, this project is very rudimentary. I focused the most on connecting user input to game controls and player physics. Most of my learning came from tweaking the acceleration/deceleration of the player based on keyboard input, as well as wrapping the player around the screen based on their position in space.

Other important game programming skills introduced in this project were player health, time, ammunition, 'lives', as well as creating and destroying enemies based on basic game conditions.
