Robot Repair

A puzzle game to help a broken robot uncover a secret message, letter by letter

Development: Unity 6, C#

Art: Autodesk Maya 2025, Blender 3.6, Procreate

Timeline: 3 Weeks

Play on itch.io

Robot Repair is a cartoon-stylized puzzle word game. It follows a brief narrative, encouraging the player to uncover meaning with interactive text objects. The development of this game focuses on events, listeners, sound, animation, and input handling. It tackles a primary goal of creating a clear game loop with a strong beginning and end, while also implementing a balanced overall feeling for the player. With a strong system of feedback, reaction, and the ability to try again, this game can be utilized for any puzzle-like experience.

About the Process

This game was inspired by the classic Hangman. It is currently based on a message that I personally chose, but I always imagined that, with more time, the game could dynamically decide new phrases by gathering information from a list of options.

I organized all possible letters, all previous guesses, and new guesses in various arrays and lists of letters in a set of global variables. It was the effort of various event listeners in Unity that consistently checked whether the player was closer to unlocking the puzzle.

I gained the most experience with Unity's animation system through this project. I was able to understand how to implement state machines in both C# and the animator's visual programming interface. Many of the animations that you see in the game are triggered based on the player's guesses.

There are also three different versions of the little hanging robot. You might notice that, as you collect more and more correct letters, he slowly becomes less damaged and more lively in his animations.
